# Feature Module: Authentication & Session Management

- **Scope:** Quản lý xác thực người dùng, đăng ký, đăng nhập Email/Password, đăng nhập Google OAuth (Supabase Auth SSR PKCE), quên mật khẩu, phiên làm việc cookie SSR và phân tách quyền hạn.
- **Architecture Reference:** `docs/architecture/authentication-architecture.md`, `ADR-0004`, `docs/features/auth/google-oauth.md`.
- **Implementation Phases:** Phase P09 (Xác thực & Quản lý Phiên), Phase P29 (Đăng nhập bằng Google OAuth).
