# Phase P20: Kế Hoạch Thi Công (Execution Plan)

## 1. Các Gói Công Việc (Work Packages)
1. **P20-WP01:** Preflight và lập kế hoạch PWA/Cache boundaries.
2. **P20-WP02:** Web App Manifest (`src/app/manifest.ts`), icons và theme metadata.
3. **P20-WP03:** Service Worker (`public/sw.js`), registration boundary và App Shell cache.
4. **P20-WP04:** Trang ngoại tuyến `/offline`, offline banner và update banner.
5. **P20-WP05:** Trải nghiệm cài đặt đa nền tảng (Chromium prompt & iOS instructions).
6. **P20-WP06:** Dọn dẹp cache riêng tư khi logout và cách ly tài khoản.
7. **P20-WP07:** Kiểm thử Android, iOS Safari, mất mạng và ranh giới không chỉnh sửa offline.
8. **P20-WP08:** Quality gates, Review, Handover và Local Git commit.
