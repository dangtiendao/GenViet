# Edge Contract: ParentChildEdge & UnionEdge

## 1. `ParentChildEdge`
- **Hướng cạnh:** Luôn luôn từ `Parent` $\rightarrow$ `Child` (Source: Parent Bottom Handle, Target: Child Top Handle).
- **Kiểu định tuyến:** Orthogonal Smooth Step routing.
- **Phong cách trực quan:**
  - *Quan hệ huyết thống xác minh:* Nét liền màu xanh lục (`#059669`).
  - *Quan hệ nuôi / đỡ đầu:* Nét đứt màu xanh dương (`#0284c7`).
  - *Quan hệ chưa xác minh:* Nét đứt màu hổ phách (`#d97706`).

## 2. `UnionEdge`
- **Hướng cạnh:** Nối từ `Person` (East handle) $\rightarrow$ `UnionNode` (West handle).
- **Phong cách trực quan:** Nét chấm màu hồng nhạt (`#f43f5e`), thể hiện liên kết hôn nhân giữa các cặp phối ngẫu.
