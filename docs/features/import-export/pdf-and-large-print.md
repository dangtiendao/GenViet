# Xuất Báo Cáo PDF & In Cây Lớn (PDF & Large-Tree Print - P27-T11, P27-T17)

## 1. Xuất Báo Cáo PDF Chuẩn Unicode Tiếng Việt
- Nhúng font tiếng Việt đầy đủ.
- Tùy chọn bảo vệ quyền riêng tư: Ẩn người còn sống, ẩn ngày tháng sinh/mất.
- Giới hạn tối đa 50-100 trang để bảo vệ tài nguyên hệ thống.

## 2. In Cây Lớn (Tiled Grid / Poster)
- Tự động phân chia khung vẽ đồ thị kích thước lớn (VD: 5000x3000px) thành lưới các trang in A4/A3 có lề xếp chồng (overlap) và dấu cắt (crop marks).
