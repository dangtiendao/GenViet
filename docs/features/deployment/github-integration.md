# Sổ Tay Tích Hợp GitHub Với Vercel (GitHub Integration - P24-T01)

## 1. Các Bước Kết Nối An Toàn (Manual Action)
1. Đăng nhập vào Vercel Dashboard $\rightarrow$ **Add New...** $\rightarrow$ **Project**.
2. Chọn kết nối với tài khoản GitHub sở hữu repository `GenViet`.
3. Chỉ cấp quyền truy cập tối thiểu (Select repositories: `GenViet` only).
4. Xác nhận cấu hình Build and Output Settings như hướng dẫn tại `vercel-project-setup.md`.
5. Điền các biến môi trường cho môi trường Production và Preview theo `environment-matrix.md`.
