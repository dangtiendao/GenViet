# GenViet Design System Documentation

Tài liệu thiết kế và hướng dẫn sử dụng thư viện UI Components, Design Tokens và Responsive Shell cho dự án **GenViet (v0.1)**.

---

## Danh mục Tài liệu

1. **[Nguyên tắc Thiết kế (Design Principles)](./design-principles.md):** Triết lý Mobile-First, trang trọng, gần gũi cội nguồn, bảo đảm khả năng tiếp cận WCAG 2.2 AA.
2. **[Hệ thống Màu sắc (Color Tokens)](./colors.md):** Bảng mã màu Semantic, Primary Emerald, Neutral Slate, Semantic Alerts.
3. **[Hệ thống Kiểu chữ (Typography)](./typography.md):** Phân cấp Font scale, hỗ trợ tiếng Việt có dấu, line height và truncation.
4. **[Hệ thống Khoảng cách (Spacing & Dimensions)](./spacing.md):** Spacing scale, touch target $\ge 44\text{px}$, kích thước Header, Sidebar, Mobile Nav.
5. **[Chính sách Breakpoints (Breakpoints & Viewports)](./breakpoints.md):** Quy chuẩn màn hình từ 320px đến 1536px, Mobile-First.
6. **[Đặc tả API Component (Component API)](./component-api.md):** Hướng dẫn props và cách dùng các UI Primitives (`Button`, `Input`, `Select`, `Dialog`, `Drawer`, `BottomSheet`, `Toast`, `Skeleton`).
7. **[Bộ điều khiển Biểu mẫu (Form Controls)](./form-controls.md):** Quy chuẩn nhập liệu và bộ điều khiển `PartialDateInput` chuyên dụng cho gia phả.
8. **[Lớp phủ & Hộp thoại (Overlays & Modals)](./overlays.md):** Quy chuẩn Modal Dialog, Side Drawer và Mobile Bottom Sheet.
9. **[Trạng thái Phản hồi (Feedback States)](./feedback-states.md):** `EmptyState`, `ErrorState`, `Toast` notifications và `Skeleton` loaders.
10. **[Khung Giao diện Điều hướng (Navigation & App Shell)](./navigation-shell.md):** Kiến trúc App Shell, Desktop Sidebar, Mobile Bottom Navigation và App Header.
11. **[Checklist Khả năng Tiếp cận (Accessibility Checklist)](./accessibility-checklist.md):** Hướng dẫn kiểm toán WCAG 2.2 AA, Keyboard navigation, Focus trap và Focus rings.
12. **[Ma trận Kiểm thử Đáp ứng (Responsive Test Matrix)](./responsive-test-matrix.md):** Bảng kịch bản kiểm thử trên các kích thước màn hình đại diện.
