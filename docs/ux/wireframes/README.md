# Bộ Tài liệu Wireframe Low-Fidelity GenViet (v0.1)

Thư mục này chứa toàn bộ các bản thiết kế khung dây tĩnh (ASCII Wireframes) cho phiên bản **GenViet v0.1**:

---

## Danh mục Wireframe Chi tiết

| Tên Wireframe | Mã tài liệu | Màn hình liên quan | Khung nhìn & Mục đích |
| :--- | :--- | :--- | :--- |
| 🖥️ **[Desktop App Shell](./desktop.md)** | `WF-DESKTOP-01` | `SCR-009`, `SCR-011` | Bố cục tổng thể trên máy tính để bàn (`1440x900px`). |
| 📱 **[Mobile App Shell](./mobile.md)** | `WF-MOBILE-01` | `SCR-009`, `SCR-011` | Bố cục tổng thể trên điện thoại (`375x667px`) kèm Bottom Nav. |
| 🔐 **[Xác thực & Đăng nhập](./auth.md)** | `WF-AUTH-01` | `SCR-001`..`004` | Đăng nhập, đăng ký, quên mật khẩu (Desktop & Mobile). |
| 📊 **[Dashboard & Tạo Cây](./dashboard.md)** | `WF-DASH-01` | `SCR-005`..`007` | Trang chủ, trạng thái rỗng và modal khởi tạo cây mới. |
| 🌳 **[Cây Gia phả Tương tác](./family-tree.md)** | `WF-TREE-01` | `SCR-009` | Sơ đồ phân tầng trực quan, các loại đường nối huyết thống. |
| 👤 **[Hồ sơ Thành viên](./person-profile.md)** | `WF-PROFILE-01` | `SCR-011` | Side panel desktop và bottom sheet di động 3 nấc. |
| 📝 **[Form Nhập liệu](./person-form.md)** | `WF-PERSONFORM-01` | `SCR-008`, `SCR-012`, `013` | Form thêm mới và chỉnh sửa hồ sơ phân nhóm gọn gàng. |
| 🔍 **[Tìm kiếm Thành viên](./search.md)** | `WF-SEARCH-01` | `SCR-010` | Command Bar `Ctrl+K` và trang tìm kiếm di động. |
| ⚙️ **[Cài đặt & Sao lưu](./settings-and-backup.md)** | `WF-SETTINGS-01` | `SCR-019`, `SCR-020` | Cài đặt cây gia phả và thẻ tải file backup JSON. |
| ⚠️ **[Trạng thái & Hộp thoại](./states-and-dialogs.md)** | `WF-DIALOGS-01` | `SCR-018`, `SCR-025` | Hộp thoại chặn lỗi chu trình, toast cảnh báo và hoàn tác. |
