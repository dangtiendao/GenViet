# Chuẩn Phạm vi Phiên bản GenViet v0.1 (v0.1 Scope Baseline)

- **Mã tài liệu:** `PROD-BASELINE-v0.1`
- **Phiên bản:** `v0.1.0-baseline`
- **Trạng thái:** `PROPOSED_FOR_APPROVAL` *(Chờ phê duyệt chính thức từ Project Owner trước khi chốt sang P02)*
- **Ngày thiết lập:** 2026-08-29
- **Người thiết lập:** Senior Product Manager & Technical Product Owner

---

## 1. Thông tin Phát hành (Release Summary)

- **Tên phiên bản:** **GenViet v0.1 (Single-owner Family Tree MVP)**
- **Loại hình sản phẩm:** Responsive Web Application.
- **Mục tiêu phát hành:** Cung cấp giải pháp số hóa cây gia phả cá nhân hoàn chỉnh, cho phép người dùng tự tạo cây từ bất kỳ thành viên nào, bổ sung thế hệ tổ tiên linh hoạt, xem đồ thị trực quan trên điện thoại/máy tính và xuất file sao lưu JSON an toàn tuyệt đối.

---

## 2. Tóm tắt Phạm vi Đã Khóa (Scope Summary)

### 2.1. Phân loại Tính năng:
- **`Must-Have` (16 hạng mục):** Xác thực Email/Pass, Quản lý cây, CRUD nhân vật, Bắt đầu từ node bất kỳ, Quan hệ Cha/Mẹ/Vợ/Con cơ bản, Mở rộng tổ tiên lên trên, Chống vòng lặp/self-link, Đồ thị phân tầng tự động (React Flow + ELK.js), Đổi người trung tâm, Zoom/Pan, Tìm kiếm có/không dấu, Mobile responsive touch, Privacy by default & RLS isolation, Xuất sao lưu JSON, Xác nhận xóa an toàn, Trạng thái Loading/Empty/Error.
- **`Should-Have` (Ưu tiên triển khai nếu không trễ lịch):** Ảnh đại diện nhân vật (Avatar), Nhập file sao lưu JSON (Restore), Khôi phục từ thùng rác, Google OAuth, Cài đặt PWA, Quản lý nhiều cây.
- **`Won't-Have` (Loại bỏ 100% khỏi v0.1):** Cộng tác nhiều người, Mạng xã hội, Chat, Lịch âm/ngày giỗ, In ấn PDF khổ lớn A0, GEDCOM, Xưng hô tự động, AI nhận diện mặt, Ứng dụng native, Chỉnh sửa offline-first.

---

## 3. Ràng buộc Kỹ thuật & Quyền Riêng tư

- **Quy mô Cây:** Lưu trữ tối đa 1.000 người/cây; kiểm thử chức năng đạt chuẩn 500 người; hiển thị mặc định 2-3 thế hệ quanh người trung tâm (50-80 nodes đồng thời).
- **Thiết bị:** Hỗ trợ đầy đủ Desktop ($\ge 1024\text{px}$), Tablet ($768 - 1023\text{px}$) và Smartphone ($360 - 767\text{px}$).
- **Trình duyệt:** Hỗ trợ 2 phiên bản mới nhất của Chrome, Safari iOS, Edge, Firefox. Cấm Internet Explorer.
- **Bảo mật:** 100% dữ liệu gia phả được bảo vệ bởi Supabase RLS, không có trang public, không lộ secret vào Git.
