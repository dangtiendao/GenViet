# Hướng Dẫn Tìm Kiếm Thành Viên (Search)

## 1. Tìm Kiếm Tiếng Việt Nhanh Chóng
- Nhập từ khóa tìm kiếm: Hệ thống hỗ trợ tìm kiếm cả tiếng Việt **có dấu** (ví dụ: *Nguyễn Văn An*) hoặc **không dấu** (*Nguyen Van An*).
- **Bộ lọc nâng cao:**
  - Lọc theo **Giới tính** (Nam / Nữ).
  - Lọc theo **Tình trạng** (Còn sống / Đã mất).
  - Lọc theo **Khoảng năm sinh** và **Khoảng năm mất**.
- **Xem trực tiếp trên cây:** Nhấn nút **"Xem trên cây"** bên cạnh kết quả tìm kiếm để điều hướng ngay tới vị trí thành viên đó trên đồ thị phả hệ.
